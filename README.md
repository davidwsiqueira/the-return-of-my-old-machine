# The Return of My Old Machine

[![MkDocs](https://img.shields.io/badge/docs-mkdocs-blue)](https://davidwsiqueira.github.io/the-return-of-my-old-machine)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

> A personal restoration and documentation project focused on reviving an old AMD-based desktop computer, Linux experimentation, and retro computing preservation.

## 📖 About

This repository contains comprehensive documentation of a hardware restoration project that transforms a forgotten desktop computer into a functional, lightweight Linux workstation. The project explores:

- **Hardware Restoration**: Diagnosing, repairing, and preserving aging components
- **Linux Experimentation**: Optimizing Linux Mint XFCE for vintage hardware
- **Retro Computing**: Exploring old games, emulation, and vintage software
- **Self-Hosting**: Running lightweight services and experiments
- **Technical Storytelling**: Documenting the journey, challenges, and discoveries

## 🎨 Documentation Theme

The documentation features a custom **Industrial UNIX Archive** aesthetic:

- Dark matte black backgrounds
- Phosphor green accents (#42a842)
- Subtle CRT terminal vibes
- Minimal glow effects
- Retro computing atmosphere
- Monospace typography

## 🚀 Quick Start

### View Documentation

Visit the live documentation: [https://davidwsiqueira.github.io/the-return-of-my-old-machine](https://davidwsiqueira.github.io/the-return-of-my-old-machine)

### Build Locally

```bash
# Clone the repository
git clone https://github.com/davidwsiqueira/the-return-of-my-old-machine.git
cd the-return-of-my-old-machine

# Install dependencies
pip install -r requirements.txt

# Serve locally
mkdocs serve

# Build static site
mkdocs build
```

This project embraces:

- **Preservation over replacement** - extending hardware lifespan

- **Learning over perfection** - experimentation and iteration
